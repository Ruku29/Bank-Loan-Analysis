# Bank-Loan-Analysis
A data-driven analysis of bank loan using MySQL , Python and Power BI to assess lending risks, track financial KPIs, and optimize approval strategies

Business Questions

1. Compare approved Vs rejected loans.
2. Identify the most common loan purpose.
3. How do age groups affect loan approval?
4. Are people with mortgages more likely to get loans?
5. Do higher credit scores lead to more approvals?
6. Which education group gets the most approvals?
7. Identify the top 5 highest-income applicants.
